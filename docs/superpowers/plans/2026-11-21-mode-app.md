# Mode app (lot 1 de l'app Android) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quand qatlia.ma est affiché dans l'app du Play Store, le site ne montre plus rien qui vend ; dans un navigateur, il se comporte exactement comme aujourd'hui.

**Architecture:** Un script en tête de page reconnaît l'app (paramètre `?app=android`, référent `android-app://com.qatlia.app`, ou mémoire de l'onglet) et pose `data-app="android"` sur `<html>` avant le premier affichage. Une règle CSS masque alors tout élément marqué `data-sells`, donc sans attendre React. Les pages d'achat et d'accueil sont redirigées à deux niveaux : par le script pour un chargement complet, par une garde React pour les navigations internes.

**Tech Stack:** Next.js 14.2 (App Router), React 18, TypeScript, Tailwind. Tests : `node --test` avec les aides de `tests/helpers/` (pas de Jest, pas de DOM).

**Spec:** `docs/superpowers/specs/2026-11-14-app-mobile-design.md`, section « Lot 1 — Mode app ». Le présent plan ne couvre que ce lot.

## Global Constraints

- Identifiant de l'app : `com.qatlia.app`. Le référent accepté est exactement `android-app://com.qatlia.app`, avec ou sans barre finale.
- Le mode ne fuit pas vers le navigateur : rien dans un cookie ni dans `localStorage`. Seul `sessionStorage` est permis.
- Aucun lien d'achat n'apparaît, même un instant, avant l'hydratation React.
- Hors de l'app, le site se comporte exactement comme aujourd'hui.
- Le serveur ne connaît pas le mode : aucune route API, aucun middleware, aucune page serveur ne change.
- Les pages confidentialité et conditions gardent leur texte actuel. Le contact support WhatsApp et e-mail, le solde, l'historique des mouvements et la mention des crédits offerts à l'inscription restent visibles.
- Chaque texte d'interface existe en `fr`, `ar` et `en` (`tests/i18n-coverage.test.js`).
- Production en ligne : une seule PR vers `main`, jamais empilée. Branche `feat/mode-app` créée depuis `origin/main` (le dossier local a du retard), dans un worktree sous `.claude/worktrees/` avec une jonction vers `node_modules`.
- Suite complète : `npm run test:node`. Dix échecs dus aux fins de ligne CRLF existent déjà sur `main` ; tout autre échec est une régression.
- Pas de `.env.local` sur ce poste : `next dev` échoue dans le middleware. L'interface se vérifie sur l'aperçu Vercel de la PR.
- Commentaires de code en anglais, messages de commit en français, comme le reste du dépôt.
- Les numéros de ligne ci-dessous sont ceux de `origin/main` au commit `6140900` ; se repérer au texte cité s'ils ont bougé.

## Review Focus

1. **Un client du site ouvre un lien depuis Gmail ou WhatsApp sur Android.** Le référent vaut `android-app://com.google.android.gm/` : le site ne doit pas passer en mode app, sinon ce client ne peut plus acheter. Test dans la tâche 1.
2. **Adresses voisines des pages redirigées.** `/credits/`, `/credits?pack=artisan` et `/ar/` sont redirigées ; `/credits-old`, `/refund` et `/w/abc` ne le sont pas. Test dans la tâche 1.
3. **`sessionStorage` refusé par le navigateur.** Le script ne doit pas planter et doit quand même activer le mode pour la page ouverte avec le paramètre. Test dans la tâche 1. Limite connue : après un rechargement complet sans paramètre (retour de la connexion Google), le mode est perdu ; c'est le point à contrôler sur Samsung Internet au lot 2.
4. **Une nouvelle page ajoute plus tard un lien vers `/credits`**, comme `/panels` l'a fait entre la conception et ce plan. Un test balaie les pages et les composants et échoue sur tout lien d'achat non marqué. Test dans la tâche 3.
5. **Déconnexion dans l'app.** Les deux déconnexions font `router.push('/')` : l'utilisateur doit arriver sur l'atelier sans voir la page d'accueil et ses tarifs. La garde de la tâche 2 rend vide le temps de la redirection ; contrôle réel sur l'aperçu à la tâche 5.

const assert = require('node:assert/strict');
const vm = require('node:vm');

const { loadTsModule } = require('./helpers/load-ts-module');

// The site knows it runs inside the Play Store app and then sells nothing
// (spec 2026-11-14, lot 1). The head script and the pure function must agree.

const storeApp = loadTsModule(path.resolve(__dirname, '..', 'src/lib/store-app.ts'));
const KEY = storeApp.STORE_APP_STORAGE_KEY;

/** Runs the head script against a fake page and reports what it did. */
function runScript({ url, referrer = '', stored = null, storageThrows = false }) {
  const { pathname, search } = new URL(url, 'https://qatlia.ma');
  const attrs = {};
  const store = stored === null ? {} : { [KEY]: stored };
  let replaced = null;
  const blocked = () => { throw new Error('blocked'); };
  const sessionStorage = {
    getItem: (k) => (storageThrows ? blocked() : k in store ? store[k] : null),
    setItem: (k, v) => { if (storageThrows) blocked(); store[k] = v; },
  };
  const window = { location: { pathname, search, replace: (to) => { replaced = to; } }, sessionStorage };
  const document = { referrer, documentElement: { setAttribute: (k, v) => { attrs[k] = v; } } };
  vm.runInNewContext(storeApp.storeAppInitScript, { window, document, URLSearchParams });
  return { attrs, store, replaced };
}

  { url: '/atelier?app=android' },

- [ ] **Step 3: Implement `src/lib/store-app.ts`**

Module pur : aucun import d'exécution, aucun accès au réseau, utilisable depuis un composant client comme depuis un test Node. Règles que les signatures ne disent pas :

- `storeAppRedirect` retire les barres finales du chemin (un chemin vide vaut `/`), puis cherche une correspondance exacte dans `STORE_APP_REDIRECTS`.
- `detectStoreApp` répond vrai si `stored === 'android'`, ou si le paramètre `app` de `search` vaut `android`, ou si `referrer`, barres finales retirées, vaut exactement `android-app://com.qatlia.app`.
- `isStoreAppDocument` répond faux quand `document` n'existe pas (rendu serveur), sinon compare l'attribut `data-app` de `<html>` à `android`.
- `storeAppInitScript` est une fonction auto-exécutée, écrite en ES5 comme `localeInitScript` dans `src/i18n/index.ts`, construite avec `JSON.stringify` à partir des constantes et de `STORE_APP_REDIRECTS` pour que la table n'existe qu'à un endroit. Dans l'ordre : lire la mémoire de l'onglet (dans son propre `try`), appliquer les trois règles de `detectStoreApp`, s'arrêter si aucune ne répond ; sinon écrire la mémoire (dans son propre `try`), poser `data-app="android"` sur `<html>`, puis, si le chemin est redirigé, poser `data-app-leaving=""` et appeler `window.location.replace(cible)`. Le tout dans un `try` global qui avale les erreurs. N'utiliser que `window.location`, `window.sessionStorage`, `document.referrer`, `document.documentElement` et `URLSearchParams`.

// /panels gained a link to /credits between the design and the build: this
// sweep is what catches the next one.

const ROOT = path.resolve(__dirname, '..');
const read = (file) => fs.readFileSync(path.join(ROOT, file), 'utf8');

/** Pages that are redirected as a whole in the app, and the back office. */
const NOT_SWEPT = ['src/app/landing-page.tsx', 'src/app/(site)/credits/', 'src/app/(site)/admin/'];

function walk(dir) {
  return fs.readdirSync(path.join(ROOT, dir), { withFileTypes: true }).flatMap((entry) => {
    const rel = `${dir}/${entry.name}`;
    if (entry.isDirectory()) return walk(rel);
    return rel.endsWith('.tsx') ? [rel] : [];
  });
}

/** The opening tag around `index`: from its `<` to the first `>` that is not an arrow's. */
function tagAround(source, index) {
  const start = source.lastIndexOf('<', index);
  const end = index + source.slice(index).search(/[^=]>/) + 2;
  return source.slice(start, end);
}

test('every way to the purchase or refund page is hidden or rerouted in the app', () => {
  const swept = [...walk('src/app'), ...walk('src/components')].filter(
    (file) => !NOT_SWEPT.some((skip) => file.startsWith(skip))
  );
  const loose = [];
  for (const file of swept) {
    const source = read(file);
    for (const match of source.matchAll(/(['"])\/(credits|refund)\1/g)) {
      const tag = tagAround(source, match.index);
      if (!/data-sells|inApp \?/.test(tag)) loose.push(`${file}: ${tag.replace(/\s+/g, ' ').slice(0, 90)}`);
